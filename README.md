# Family Meal Planning Resources

A free static website designed for GitHub Pages. It provides useful meal-planning resources while naturally directing interested visitors to **The Man That Cooks Sometimes**.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `family-meal-planning`.
2. Upload `index.html` from this package to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the deployment/source section, publish from the `main` branch and root folder.
5. Once GitHub gives you the live URL, replace `YOUR-GITHUB-USERNAME` in the canonical URL inside `index.html` with your actual GitHub username.
